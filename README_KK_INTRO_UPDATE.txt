CELINE CLOSET - BẢN CẬP NHẬT TRANG MỞ ĐẦU THEO KHUNG GIỚI THIỆU KK FASHION

Nội dung đã chỉnh:
- Làm lại trang mở đầu tại: src/main/webapp/index.jsp
- Bố cục mới gồm: thanh miễn phí vận chuyển, header menu ngang, breadcrumb, khối giới thiệu, liên kết Lookbook/Showroom, phần Đôi nét, Về sản phẩm, Về khách hàng, Hướng dẫn mua hàng, Thông tin liên hệ và footer nhiều cột.
- CSS mới đã thêm cuối file: src/main/webapp/css/style.css
- Không sao chép nguyên văn nội dung/ảnh của KK Fashion; chỉ lấy cảm hứng về bố cục và tinh thần trình bày để dùng cho thương hiệu Celine Closet.

Eclipse Import / Root Directory:
Chọn thư mục: Celine Closet

Cách import:
File > Import > Maven > Existing Maven Projects > Browse đến thư mục Celine Closet > Finish.
Sau đó: Maven > Update Project > Force Update, rồi Project > Clean.

Ghi chú:
Nếu muốn đổi thông tin thật của shop, mở src/main/webapp/index.jsp và sửa các dòng Hotline, Email, Showroom, thời gian mở cửa.
